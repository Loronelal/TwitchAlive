# Twitch Keep Alive

Расширение для Chrome, которое держит стрим активным в свёрнутой вкладке,
само забирает дропсы и бонусы канала и показывает на странице дропов, что уже
получено.

Всё работает локально: настройки, избранное и статистика хранятся только
в профиле браузера, на сервер ничего не уходит.

## Что умеет

* **Не даёт стриму встать на паузу.** Свёрнутая вкладка Twitch остаётся для
  плеера «видимой», поэтому просмотр и дропсы продолжают идти.
* **Поднимает видео, если оно остановилось.** Нажимает play, если плеер встал.
* **Забирает дропсы.** Сам нажимает «Получить», когда награда готова.
* **Забирает бонус канала.** Прожимает кнопку бонуса, когда она загорается,
  и считает статистику по стримерам.
* **Помнит избранные игры** на странице дропов и умеет показывать только их.
* **Отмечает, что уже получено:** статусы в инвентаре и счётчики наград
  на «Все кампании».
* **Уведомляет,** когда стрим закончился или стример сменил игру.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку
   `TwitchAlive`.
4. Откройте или обновите вкладку Twitch (F5).

Если расширение уже установлено и вы обновили файлы — нажмите ⟳ на его
карточке в `chrome://extensions`, затем F5 на вкладке Twitch.

Расширения из папки не обновляются сами: после правок файлов Chrome видит
новую версию только после ⟳.

## Иконка расширения

Клик по иконке открывает настройки и статистику.

| Опция | Что делает |
| --- | --- |
| Держать вкладку активной | стрим не встаёт на паузу в свёрнутой вкладке |
| Восстанавливать воспроизведение | нажимает play, если видео остановилось |
| Забирать дропсы | автоматически нажимает «Получить» |
| Забирать бонус канала | собирает бонусные очки, когда загорается кнопка |
| Уведомления | сообщает о конце стрима и смене игры |

Изменения применяются сразу во всех открытых вкладках Twitch, перезагружать
страницу не нужно.

Ниже — **статистика бонусов канала**: сколько раз собран бонус, по каким
стримерам и примерная сумма очков (50 за бонус). Счётчик срабатывает в момент
нажатия кнопки, повторный клик по тому же бонусу в течение минуты не
считается. Кнопка «Очистить статистику» обнуляет данные.

## Страница дропов

### Избранные игры

На `https://www.twitch.tv/drops/campaigns` у каждой игры появляется звёздочка:

* наведите курсор на карточку — появится ☆;
* клик — игра добавлена в избранное, ★ стала золотой и видна всегда;
* повторный клик — убрать из избранного.

В полосе вкладок дропов появляется пункт **«★ Избранное (N)»**:

* клик — показывает только избранные игры, пункт подсвечивается фиолетовым;
* стрелка ▾ — список избранного, переключатель «Только избранное»,
  «Очистить список» и кнопка **«Собрать данные по всем играм»**;
* если избранное опустело, фильтр выключается сам, чтобы страница не
  осталась пустой.

Кнопки и панель есть только на страницах `/drops`. На канале, в ленте и
каталоге они не рисуются.

### Инвентарь: что уже получено

На `https://www.twitch.tv/drops/inventory` рядом с каждой кампанией
появляется отметка:

| Отметка | Значение |
| --- | --- |
| `✓ Получено` (зелёная) | все живые награды забраны, забирать нечего |
| `Забрать` (жёлтая) | просмотр закончен, но награду нужно забрать или подключить |
| `Недоступно` (серая) | все награды кампании истекли |
| `85%` (серая) | кампания не досмотрена, число — ближайшая к финишу награда |

Истёкшие награды, которые Twitch помечает как недоступные, в расчёт не идут:
из-за них кампания не должна навсегда висеть на 85%.

В хедере появляется вкладка **«✓ Готово (N)»** — она прячет полностью
собранные кампании. Состояние запоминается.

Отметки обновляются сами: когда прогресс доходит до 100% или появляется
кнопка награды.

### «Все кампании»: счётчик наград

На `https://www.twitch.tv/drops/campaigns` рядом с названием игры появляется
счётчик собранных наград: `3/5`, а когда собрано всё — зелёное `✓ 5/5`.
Такой же счётчик есть у названия кампании в раскрытом блоке.

Зелёным счётчик становится только при полном сборе. Если часть наград
истекла, остаётся серое `2/5`.

«Собрано» определяется по блоку **«Получено»** внизу инвентаря: сначала
сверяется картинка награды, затем название. Это точнее полосок прогресса —
полоска может быть 100%, а награда ещё не забрана. Полученные награды в
раскрытых категориях подчёркнуты зелёной полосой.

* Раскрыли кампанию — счётчик считается по видимым наградам именно этой
  кампании.
* Кампания свёрнута — показывается сохранённый точный замер строки, чтобы
  числа не прыгали между кампаниями под одной шапкой.

### Кэш и подгрузка

Инвентарь листается кнопкой «Загрузить еще», поэтому статистика копится:
кампании, ушедшие с загруженной страницы, остаются в кэше до 14 дней.

При открытии инвентаря расширение само нажимает «Загрузить еще» (до 8 раз за
визит), чтобы в кэш попали кампании со всех страниц. Строки, которых ещё нет
в кэше, читаются по мере прокрутки.

Полный проход по всем строкам можно запустить вручную: стрелка ▾ у
«★ Избранное» → **«Собрать данные по всем играм»**. На длинной странице
(100+ строк) это занимает около минуты.

Если Twitch поменял награды кампании (новый сезон под тем же названием),
счётчики пересчитываются заново — старые числа не подмешиваются.

## Уведомления

Расширение сообщает:

* стрим закончился;
* стример сменил игру.

Для этого браузер должен разрешить уведомления. Отключить их можно тумблером
«Уведомления» в popup.

## Частые вопросы

**Стрим всё равно завис, хотя вкладка свёрнута.**
Keep-alive убирает паузу из-за невидимой вкладки, но не лечит сеть, рекламу и
другие расширения. Если в консоли есть `ERR_BLOCKED_BY_CLIENT` или зависает
рекламная плашка `0:00`, добавьте `twitch.tv` в исключения блокировщика
рекламы и перезагрузите страницу.

**Почему не растёт статистика бонусов?**
Бонус появляется периодически. Расширение проверяет кнопку каждые 10 секунд и
считает только собственные нажатия. Если тумблер «Забирать бонус канала»
выключен, статистика не пополняется.

**Почему счётчиков на «Все кампании» нет?**
Нужен хотя бы один визит на `/drops/inventory`, чтобы расширение получило
данные. Если кампании нет в инвентаре, запустите «Собрать данные по всем
играм» в меню избранного.

**Почему счётчик показывает не всё?**
Проверьте блок «Получено» внизу инвентаря: расширение считает собранным
только то, что Twitch туда записал. Полоска 100% без записи в «Получено» не
считается.

**Куда уходят данные?**
Никуда. Избранное, настройки, статистика и кэш лежат в `chrome.storage.local`
вашего профиля Chrome.

**Можно ли использовать вместе с другими авто-кликерами?**
Можно, но они будут дублировать друг друга. Если награды ведут себя странно,
оставьте один авто-кликер.

## Ограничения

* Только Chrome и браузеры на его движке (Manifest V3).
* Расширение не блокирует рекламу и не обходит блокировщики — наоборот,
  заблокированный рекламный запрос может подвесить плеер.
* Оценка очков в статистике примерная: 50 очков за бонус.
* Кнопка бонуса ищется по подписи «Получить бонус», поэтому интерфейс Twitch
  должен быть на русском.
* Разметка Twitch может меняться. Если счётчики или кнопки пропали после
  обновления сайта, расширение нужно поправить под новый DOM.

## Для разработчика

| Файл | Назначение |
| --- | --- |
| `manifest.json` | Manifest V3, порядок и миры content scripts |
| `keepalive.js` | подмена видимости в MAIN-мире, `document_start` |
| `content.js` | настройки, авто-воспроизведение, авто-клики, уведомления, статистика |
| `settings.js` | значения настроек по умолчанию для content script и popup |
| `popup.html`, `popup.js` | окно настроек и статистики |
| `favorites.js` | избранное, счётчики и разметка страниц дропов |
| `gql-sniffer.js` | перехват GraphQL-ответов инвентаря в MAIN-мире |

**Keep-alive.** `keepalive.js` запускается в MAIN-мире: из изолированного мира
content script'а страница не видит подмену `document.hidden`. Скрипт
подменяет `Document.prototype.hidden`, `visibilityState`, `webkitHidden`,
`webkitVisibilityState` и `hasFocus()`, а события `visibilitychange`,
`webkitvisibilitychange`, `blur` и `focus` глушит в capture-фазе до
обработчиков Twitch. Тумблер в popup передаёт состояние в MAIN-мир
сообщением: у `keepalive.js` нет доступа к `chrome.storage`.

Сознательно не трогаются таймеры и `HTMLMediaElement.prototype.pause`:
урезание `setTimeout`/`setInterval` ломает буферизацию и рекламу, а блокировка
`pause` — кнопку паузы.

**Данные инвентаря.** Счётчики собираются из трёх источников:

1. разбор страницы `/drops/inventory` при открытии;
2. повторный GraphQL-запрос, параметры которого подсмотрел `gql-sniffer.js`;
3. разбор HTML, если GraphQL не ответил или схема ещё не проверена.

Кэш и настройки: `chrome.storage.local` (`inventoryStats`, `favoriteGames`,
`onlyFavorites`, `settings`, `bonusStats`).

**Проверка.** `dev/test.html` — копия разметки страницы дропов с ассертами.
Из папки проекта:

```powershell
python -m http.server 8123
```

Затем в headless Chrome:

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu `
  --user-data-dir="$env:TEMP\tak" --virtual-time-budget=12000 --dump-dom `
  "http://127.0.0.1:8123/dev/test.html"
```

В конце DOM будет `<pre id="result">PASS</pre>` или список упавших проверок.
`?both=1` — тот же тест вместе с `content.js`.
